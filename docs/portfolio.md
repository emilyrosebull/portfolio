## Task It: Overview and Configuration
**Type:** Conceptual overview / configuration guide
**Audience:** Employers (HR or IT) configuring the Task It application for their employees.

Because my most recent League writing samples are private, I documented a basic application called "Task It" that I built with Claude. Task It allows employees to track their work and personal tasks in one centralized application. It also includes an admin console where employers can configure some of the application's appearance and settings.

While Claude built Task It, the application and configuration ideas are my own, and I wrote these docs without AI. I know this application isn't fancy, but it's a good subject for writing samples.
